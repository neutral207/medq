# MedQ Starter

This is a minimal starter following the requested layout.

## Quick start (dev)
1. Install Docker Desktop.
2. From repo root: `docker-compose up --build`
3. Open http://localhost:3000 for the web stub, http://localhost:5000/health for API.

Frontend uses a very light vanilla JS placeholder so there is no heavy tooling.
Swap in React later using your preferred build tool.
